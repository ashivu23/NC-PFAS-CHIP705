Project Overview

This project analyzes PFAS contaminant monitoring results across North Carolina public water systems using EPA UCMR 5 data.

Project Objectives

Examine PFAS monitoring results.

Compare numeric results with results below MRL.

Identify the most frequently reported PFAS compounds with numeric results.

Discuss potential public health implications.
